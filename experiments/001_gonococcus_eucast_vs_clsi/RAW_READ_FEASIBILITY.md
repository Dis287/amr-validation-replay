# Dataset-2 raw-read reconstruction feasibility

## Verified input route (2026-09-29)

The original Hicks S7 table identifies 1,102 dataset-2 runs. ENA's official
`read_run` filereport resolves all 1,102, each with two paired FASTQ URLs,
byte sizes, and MD5 hashes. `ena_dataset2_manifest.tsv` is the filtered,
sorted manifest, with S7 dataset and AZM MIC columns joined by exact Run ID.
It is generated by `build_ena_manifest.py` from S7 and three study reports:

```text
https://www.ebi.ac.uk/ena/portal/api/filereport?accession=ERP008891&result=read_run&fields=run_accession,fastq_ftp,fastq_bytes,fastq_md5,library_layout&format=tsv
https://www.ebi.ac.uk/ena/portal/api/filereport?accession=ERP000144&result=read_run&fields=run_accession,fastq_ftp,fastq_bytes,fastq_md5,library_layout&format=tsv
https://www.ebi.ac.uk/ena/portal/api/filereport?accession=ERP001405&result=read_run&fields=run_accession,fastq_ftp,fastq_bytes,fastq_md5,library_layout&format=tsv
```

Measured from the downloaded reports and S7:

- target runs: **1,102 / 1,102 resolved**
- paired FASTQ files: **2,204**
- summed reported compressed FASTQ bytes: **344,835,597,770 (344.84 GB)**
- manifest SHA-256: `f15dfdcdf649e5e4a067e4bcdc1b643c1a124fcba7d6d24bfe135d992f58610f`

This workspace has about 30 GB free and currently lacks SPAdes, DSK, SEER,
Kover, and R/ranger. A full download held at once exceeds capacity. Streaming
one run at a time might avoid the storage limit, but 344.84 GB of transfer,
assembly compute, version matching, and the multi-million-feature modeling
cost remain unmeasured. No faithful model run has occurred.

## Reconstruction boundary

The verified Zenodo archive covers the identical dataset-2 isolates but was
assembled with Velvet for the 2016 source study. It cannot stand in for the
SPAdes-derived 31-mers described by Hicks without measuring and reporting
the feature difference. The original seeds, outer partitions, model objects,
and per-isolate predictions remain unverified. Even a fresh SPAdes run with
ten matched outer partitions would be a **method reconstruction**, not exact
numerical reproduction, unless those original artifacts are recovered.
